# EBAC Jobs — exercício de CSS-in-JS

Projeto React com TypeScript convertido de CSS Modules para Styled Components.
A estilização do cabeçalho, hero, formulário de pesquisa, componente de vaga,
lista de vagas e estilos globais está organizada em arquivos `styles.ts`.

## Como executar

```bash
npm install
npm start
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Como gerar a versão de produção

```bash
npm run build
```
